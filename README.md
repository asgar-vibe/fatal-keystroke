### Cyberpunk Detective / Hacking Typing Game

> **System:** `CYBER-INTELLIGENCE DIVISION // AKIRA WAEWBANDHIT (ASGAR)`  
> **Status:** `MIL-SPEC // CONNECTED - ENCRYPTED NODE`

## 🕹️ Overview
**Fatal Keystroke** is a high-octane retro-cyberpunk hacker detective typing game. Step into the terminal workstation of an elite cyber-forensics operative infiltrating the Zurich Underground R&D complex of **NeuroTech Nexus Corp.**

Type realistic shell sequences under active counter-ICE trace pressure, decode forensic evidence, uncover classified communications, and unmask the corporate assassin behind the death of Chief Neural Architect Dr. Ashira Waewbandhit.

---

## 🌟 Key Features

1. **Retro Hacker Terminal Aesthetics:**
   - Deep dark slate terminal with neon green phosphor glow and chromatic CRT aberration.
   - Customizable CRT scanlines overlay and radial screen vignette curvature.
   - Blinking retro block cursor (`█`) and real-time character-level feedback.

2. **10-Tier Progressive Detective Campaign:**
   - **Case:** `CASE-0x89 // OPERATION BLACK CHIMERA`
   - **Stages 1 to 10:** Line counts scale from **5 lines** in Stage 1 up to **20 lines** in the master root breach of Stage 10.
   - **Dynamic ASCII Topography:** Circuitry and network diagrams evolve in real-time as nodes fall.
   - **Progressive Evidence Stream:** Unmask categorized clues (`[INTERCEPT]`, `[CREDENTIAL]`, `[IDENTITY]`, `[FINANCIAL]`).

3. **Active Trace Back & Survival Loop:**
   - **Trace Detection Meter (0% to 100%):** Passive creep activates on first keystroke.
   - **Typo Penalty:** Typos trigger glitch screen shake and spike trace alert levels.
   - **Completion Relief:** Finishing command lines and clearing stages significantly cools trace connection risk.
   - **Critical Threat Alert:** Pulsating red emergency alert triggers when trace reaches `>= 80%`.

4. **Difficulty Level Calibration:**
   - `EASY`: **1.4x Time** (Reduced trace creep, -8% relief per line, +3% typo penalty).
   - `NORMAL`: **1.0x Time** (Balanced tension, -6% relief per line, +5% typo penalty).
   - `HARD`: **0.75x Time** (High-intensity speed challenge, -4.5% relief per line, +7.5% typo penalty).

5. **Case-Insensitive Typing Mode (`RELAXED [Aa]`):**
   - Toggle between `STRICT [A≠a]` (exact uppercase/lowercase match) and `RELAXED [Aa]` (case-insensitive mode where `S` and `s` are accepted interchangeably).

6. **International Keyboard Safeguard:**
   - Zero `~` or grave accents used in target command paths.
   - Explicit IME key filtering so language-switching keys on Thai keyboard configurations never cause accidental typo penalties.

7. **Forensic Verdict Deduction Modal:**
   - Full case breakdown upon clearing all 10 stages: culprit profile, criminal motives, evidence recovery ledger, and Detective Intrusion Rating (`RANK S / A / B / C`).

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/asgar-vibe/fatal-keystroke.git
cd fatal-keystroke
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 4. Build for Production
```bash
npm run build
```
The compiled bundle will be generated in `/dist`.

---

## 🌐 Deployment to GitHub Pages

The project is pre-configured with relative base paths (`base: './'`). You can deploy directly to GitHub Pages:

```bash
npm run build
```
Commit the output or use the standard GitHub Actions workflow for static Vite deployment.
